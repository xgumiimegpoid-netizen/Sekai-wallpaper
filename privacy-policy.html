Política de Privacidad

Última actualización: 28 de mayo de 2026

1. Información que recopilamos

Esta aplicación no recopila, almacena ni comparte ningún dato personal del usuario. No se requiere registro, inicio de sesión ni ningún tipo de identificación para usar la aplicación.

2. Permisos solicitados

La aplicación solicita los siguientes permisos exclusivamente para su funcionamiento:

  • Almacenamiento: Para guardar wallpapers en la galería del dispositivo.
  • Internet: Para cargar los wallpapers desde los servidores remotos.
  • SET_WALLPAPER: Para establecer imágenes como fondo de pantalla.

Ninguno de estos permisos se usa para recopilar información personal.

3. Datos de terceros

La aplicación carga imágenes desde URLs públicas alojadas en GitHub y CDNs. No controlamos ni almacenamos el contenido de dichas imágenes. Todo el contenido proviene de contribuciones comunitarias.

4. Servicios de terceros

La aplicación utiliza GitHub (raw.githubusercontent.com) y jsDelivr (cdn.jsdelivr.net) para servir contenido. Estos servicios tienen sus propias políticas de privacidad.

5. Cambios a esta política

Podemos actualizar esta política de privacidad ocasionalmente. Se recomienda revisarla periódicamente.

6. Contacto

Si tienes preguntas sobre esta política de privacidad, puedes contactarnos a través del repositorio oficial de la aplicación.
